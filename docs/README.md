## 这是什么

本目录是"零号改造体" Mod 的策划与设计文档集。Mod 在原版当铺经营之上叠加一层**改造体经营系统**：

- 玩家是实验室出逃的"零号改造体"，或通过"改造体之友"路线接受改造；
- 白天经营当铺，晚上制造/销售植入物、把顾客变成同类、给同类派活；
- 所有行动都会推高治安部警觉度，形成"滚雪球 vs 被追查"的拉扯；
- 长期目标分"支配"与"革命"两条路线（后续企划）。

**本阶段只做核心功能**。重要剧情、任务线、关键 NPC 特制植入物、结局演出均为后续企划，文档中只保留状态门控与接口占位。

## 核心设计一句话

> 用一间合法当铺做掩护，把植入物卖出去、把顾客变成同类、把同类派出去干活；每多一个同类，治安部就更近一步。

### 三条身份路线

| 身份 | 一句话 |
|---|---|
| 零号改造体（开局特质） | 天生掌控，无随机改造体事件，靠逃逸进度被追查 |
| 接受改造（任务线） | 后来成为同类，获得电量池，警觉度一开始就激活 |
| 改造体之友（任务线） | 不同化，只做朋友；声望封顶 99，永远无法完全掌控 |

### 核心循环

```
白天营业 → 卖植入物/处理"人类" → 闭店结算 → 感染判定 → 改造体报到
   ↑                                                    ↓
   └──────────── 夜间指令 → 产出/警觉度/追查 ←──────────┘
```

## 数值与实现约定

- 所有数值为**建议初值**，以 `config/*.json` 为准；
- 规则硬约束标注 `【锁定】`，实现不得随意改动；
- 物品/特质/科技/事件 ID 统一前缀（见 `03` §11）；
- 文档与配置同步更新，改数值先改 `03` 再改配置；
- 剧情相关只留接口，不在核心文档里写死；
- **技术事实**：Mono + 游戏自带 ModLoader；优先 `ModHook`/`ModHelper`，少用 Harmony；
- **改造体声望**首选显示在原版派系栏（需 Harmony/反射；回退 `ModData` + 自建面板）。

1. **单一事实源**：规则以 `01` 为准，数值以 `03` 为准，流程以 `02` 为准；冲突时先改主文档再同步。

4. **技术假设标注**：未验证的 API/机制在 `04` 与 `research` 中标记"待验证"。
5. **不写死剧情**：任务线/结局只保留状态与接口。
