## 一、五项确认事项的结论

### 1. 版本号随游戏更新变化

**已核实**：本机游戏已从 `26496118` 更新到 **`26525552`**（2026-11-09 21:06，`Probably Stolen.exe` 与 `Assembly-CSharp.dll` 时间戳同步更新；DLL 从 4,752,136 → 4,820,224 字节）。  
**落地**：
- 文档不再把 build 当固定前置，改为"**运行前检查 + 每次更新后复验**"；
- `manifest.xml` 的 `GameVersions` 用范围（如 `1.0.x`），不写死 build；
- 每次游戏更新后执行：读 `steamapps/appmanifest_4348910.acf` 的 `buildid`/`LastUpdated` → 重跑符号提取 → `mod-scan` → 冒烟测试；
- 新增 `research/version-watch.md` 记录本次差异（946→949 类型；`ModHelper` 143→165 方法；关键 API 仍在）。

**复验结论**：`ModLoader`/`ModHook`/`ModHelper`/`StoreReputation`/`StoreClientManager`/`AugHelper`/`ContrabandHelper`/`HusbandryHelper` 等关键类型仍在；`ModHook` 的顾客生成/睡眠/夜间服务/卷帘门/外出事件均存在。

### 2. "改造体行动中"按钮与竖排进度条

**按你的描述落地为 UI 规格**：
- **入口**：闭店后（卷帘门关闭/营业结束），在**门右侧到柜台左侧**出现按钮，文字"改造体行动中"；点击打开同名面板。
- **显示**：身体电量 + 本 Mod 主体内容，使用**竖排进度条**，**绿/黄/红**三段配色，条上/条旁显示数字。
- **建议条项**：电量、改造体声望、警觉度、逃逸进度（ZERO）、网络状态（HIDDEN/TASKED/AUTONOMOUS 计数）。
- **配色建议**：电量/声望/网络：≥60% 绿、30–59% 黄、<30% 红；警觉度反向：<30 绿、30–59 黄、≥60 红；逃逸进度反向。
- **交互**：点击条可展开详情（来源/增减提示）；闭店后默认弹出一次，之后可再次点按钮打开。

### 3. 现有机器换皮

**确认采用**：P0 不新增 2×2 放置系统，直接复用现有 2×2 机器换皮/改配方；你在 §2.2 补充的机器内部规格已整理进 §5.2：
- 电池槽 ×1、供料栏 2×6、产物栏 2×6、改造体核心 ×1；
- 初始：2 废金属 → 过夜 → 1 电子零件；
- 升级：废金属（12 次，每次 +1 格）、金属锭（按纯度 +24 格）、走私者暗格（+48 格 + 暗格效果）、储存区（+96，一次性）、储存区扩容单元（最终 +192）；
- 拖物品到"改造体核心"升级工具。

> **待确认**：§5.2 原句"被治安部看到就。"不完整；我暂补为"被治安部看到会触发盘查/没收"，请在文档里确认具体后果。

### 4. 原版手术工具

**确认**：你指的是原版**动物手术工具**——`HusbandryHelper.InitAnimalSurgeryTool`，当前只能给鲟鱼用，但物品分类是**医疗品**，会吸引医生顾客。  
**落地**：
- "人类"改造的手术路径改为使用该工具，不再引用"约 200 信用点的人用手术工具"这一未证实说法；
- 工具**不消耗**（按你之前规则），改造进度**非常快**；
- 需要给"人类"物品增加自定义手术交互；原版 `CanOperateOnAnimal`/`OperateOnAnimal` 只针对动物，Mod 需另挂或 patch；
- 医生顾客被医疗品吸引的原版逻辑可直接复用。

### 5. 原版派系栏塞入"改造体"派系

**按你的确认调整方向**：优先塞入原版派系栏（工坊已有额外派系声望 Mod 先例；原版卡特尔为仅化学家开局的隐藏派系）。  
**技术复核（build 26525552）**：`Assembly-CSharp` 中**没有** `AddFaction`/`CreateFaction` 这类官方方法；`StoreReputation` 仍是按固定派系写死的方法，`ReputationUIManager` 是固定列表。  
**结论**：可行，但要走**Harmony/反射扩展**（参考工坊派系 Mod 的具体 patch 点），不是纯官方 API；风险中等。
- 首选：扩展 `StoreReputation`/`ReputationUIManager`/`FactionStatusList`，把"改造体"作为第 6/7 个可见派系；
- 回退：`ModData` 独立变量 + 自建面板（原方案）；
- 开发前建议先做 1 天技术验证，确认工坊同类 Mod 的 patch 点与存档兼容性。
