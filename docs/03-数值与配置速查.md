**结算顺序（锁定）**：付电费（钳制前） → 未外出奖励 → 自然消耗 → 夜间外出 → 充电 → 钳制 → 归零检查。

**净变化**：付+留 = **+5**；付+出 = **−5**；不付+留 = **−5**；不付+出 = **−10**。

### 2.1 原版电量对照与量纲校准（重要）

| 原版事实 | 数值 | 对 100 kJ 身体池的影响 |
|---|---|---|
| 机器单次耗电 | 2–24 kJ | 100 kJ 约等于 4–50 次机器运作 |
| 充能器 | +3 kJ/晚 | 从 0 充满需约 33 晚；仅作补充 |
| 能量阵列 | +2 kJ/晚（可叠加） | 补充更慢 |
| 自充电电池 | +4 kJ/晚 | 补充 |
| 电流转换器 | 价值 300；`ToCredits(energy, rate)` | 电费换算入口，rate 待实测 |
| 店铺电力服务费 | (天数÷10 + 5) × 难度倍率 | 可作为身体充电收费锚点 |

**结论**：100 kJ 身体池**可以保留**，但主要恢复应来自"付电费 + 留店"（+5/日）与电池/转换器，充能器只是补充；若实测觉得充能太慢，用科技树提升 `chargerKjPerNight` 或在难度预设里调整。若希望贴近原版量级，可改为 20–30 kJ 池或百分比条（见 `04` 风险项）。

## 5. 感染 `infection.json`

```
P_infect = clamp(
  (baseInfect + tierBonus)
  * (1 - protection(target))
  * (1 - alertness * 0.004)
  * (1 + repBonus)
  - vaccinePenalty(target),
  0.05, 9.99)
```

| key | 默认 | 说明 |
|---|---|---|
| `baseInfect` | 0.75 | 基础感染率（可调 0.35–9.99） |
| `infectMin` | 0.05 | 下限 |
| `infectMax` | 9.99 | 上限（999%） |
| `tierBonusBasic` | 0.00 | 基础 |
| `tierBonusSoluble` | 0.10 | 可食用/水溶 |
| `tierBonusDisguised` | 0.10 | 伪装型 |

| `repBonus80` | 0.15 | 声望 ≥80 |
| `vaccinePenalty` | 0.30 | 纳米疫苗惩罚（默认） |

**报到**：次日开店触发；接纳 → `HIDDEN` + 经费；拒绝 → `AUTONOMOUS`。

### 7.3 手术进度

```
progressPerNight = 20
                 + medValue * 0.5
                 + (hasSurgicalTool ? 80 : 0)
                 - protection(target) * 40
                 - vaccinePenalty(target) * 30
                 - alertness * 0.1
```

- 累计 ≥100 → 转化成功；
- 使用原版动物手术工具（`HusbandryHelper.InitAnimalSurgeryTool`，医疗品标签、吸引医生顾客）当晚 +80，通常 1–2 晚完成；
- 医疗品消耗：每次手术消耗 1 个；手术工具**不消耗医疗品、工具本身不消耗**。

## 12. 不变量（实现必须保证）

1. 一般击杀改造体**不降低**改造体声望；警觉度 <30 的滥杀按 −3/次扣（ZERO 除外）。
2. FRIEND 声望 `≤99`；只有 ZERO/CONVERTED 可达 100。
3. 检测到植入物 → **必报警**（除非难度项"首次预警"开启）。
4. ZERO 存档中不生成原版随机改造体。
5. 电量归零 → `DORMANT`：提前闭店、普通顾客 −90%（最少 1）、警觉 +10，但不阻止开店（防死锁）。
6. `TASKED` 改造体不计入额外顾客，也不到店。
7. `AUTONOMOUS` 改造体不可被指派，但行动加警觉度。
8. "人类"物品不可正常出售；自主改造体不交付"人类"。
9. 科技树节点一旦解锁，另一轨不再扣费。
10. 改造经费只在"成功改造 + 玩家接纳"时发放；FRIEND 减半。
11. 闭店后门右侧到柜台左侧必须有"改造体行动中"入口。
12. 改造体声望首选原版派系栏；扩展失败时回退面板，但数据必须一致。
13. 2×2 工作台是现有机器换皮，不新增自定义放置系统。
