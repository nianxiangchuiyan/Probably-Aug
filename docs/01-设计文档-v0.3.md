## 1. 设计概览

### 1.1 核心幻想

> "你不是被感染的。你是被释放的。超级 AI 把'修正文明'的权限交给了你，而你现在只剩一间当铺、一具需要充电的身体，和一张能骗过所有人的脸。"

玩家白天经营当铺，夜晚经营一张**改造体网络**：制造植入物、把它伪装成商品卖出去、在睡梦中把顾客变成同类，再给同类派活。所有收益都伴随一个代价——治安部的警觉度。

### 1.2 设计支柱

1. **伪装经营**：核心乐趣是"在合法当铺的外壳下完成非法转化"，风险来自暴露而非战斗。
2. **网络滚雪球**：改造体越多， nightly 产能越高，但警觉度与不可控性同步上升。
3. **双资源拉扯**：信用点（经营）与电量（生存）互相争抢，付电费/外出/充电都是取舍。
4. **身份差异**：零号、接受改造、朋友三种身份给出不同的上限、风险与玩法，不是简单换皮。

### 1.3 核心循环

```
┌──────────────────────────── 白天（营业） ────────────────────────────┐
│ 接待顾客 → 卖货/收购 → 识别改造体顾客 → 处理"人类"物品 → 查看日历   │
│        ↑                                      ↓                     │
│   电量消耗/充电                          植入物售出（记录待感染）    │
└──────────────────────────────────────────────────────────────────────┘
                              ↓ 闭店
┌──────────────────────────── 夜晚（结算） ────────────────────────────┐
│ 支付电费 → 电量结算 → 感染判定 → 改造体报到 → 指派夜间指令 → 指令结算 │
│        ↓                                      ↓                     │
│   逃逸进度/警觉度更新 ←────────────── 治安部追查与事件              │
└──────────────────────────────────────────────────────────────────────┘
                              ↓ 次日
                        新顾客 / 新事件 / 新风险
```

### 1.4 体验节奏（目标）

| 阶段 | 天数（建议） | 玩家在做什么 | 系统压力 |
| --- | --- | --- | --- |
| 早期 | 1–8 | 造基础植入物、混在容器商品里卖、攒第一批量改造体 | 电量紧、警觉度低、容错高 |
| 中期 | 9–25 | 科技树、伪装/光学迷彩、夜间指令、处理"人类"、压警觉度 | 警觉度上升、防护/鉴别出现 |
| 后期 | 26+ | 网络规模化、世界事件、身份路线收束 | 治安部调查、失控改造体、结局门控 |

> 以上天数为**调参目标**，不是硬性设计。

## 2. 玩家身份与开局特质

### 2.1 身份枚举

| 身份 | 枚举值 | 获得方式 | 说明 |
| --- | --- | --- | --- |
| 普通玩家 | `BASE` | 默认 | 无零号特质；可走原版改造体危机内容；声望可积累 |
| 任务可接 | `QUEST` | BASE 且声望 ≥30 | "改造体之友"入口已解锁（任务内容后续企划） |
| 零号改造体 | `ZERO` | 开局选择特质"零号改造体" | 声望初始 100；无随机改造体事件；有逃逸进度 |
| 接受改造 | `CONVERTED` | QUEST 中选择接受改造 | 获得电量池与改造体能力；警觉度初始激活；可到 100 |
| 改造体之友 | `FRIEND` | QUEST 中选择作为朋友加入 | 无电量池、无科技树；声望硬上限 99 |
| 背叛者 | `BETRAYED` | QUEST 中选择背叛 | 声望锁定 -100；改造体敌对 |

### 2.2 开局特质：零号改造体

- **特质 ID**：`trait.aug.zero`
- **互斥**：与原版"改造体危机"特质（`trait.aug.crisis`，名称以游戏内为准）互斥。
- **互斥实现**：特质选择 UI 中双向禁用；存档加载时若检测到同时存在，以"零号改造体"为准并移除危机特质，写入日志（防坏档）。
- **选择后的初始化**：
  - 身份 = `ZERO`；
  - 改造体声望 = 100（锁定下限 100，不因击杀下降）；
  - 身体电量 = 100/100 kJ；
  - 逃逸进度 = 0（每日 +1~2，行动额外加）；
  - 警觉度 = 0 且未激活（逃逸进度满 100 后激活）；
  - 解锁：改造体植入工具（2×2 设施）、对外供电接口 ×2、科技树（科研轨）。
- **抑制原版事件**：`ZERO` 存档中，原版随机改造体生成/改造体危机事件权重置 0；由玩家的植入物与网络替代。

### 2.4 身份切换规则

```
BASE --声望≥30--> QUEST
QUEST --接受改造--> CONVERTED   （声望保留当前值，获得电量池/科技树）
QUEST --作为朋友--> FRIEND      （声望保留当前值，上限锁 99）
QUEST --背叛-----> BETRAYED    （声望锁 -100，改造体敌对）
QUEST --暂不选择--> QUEST      （可稍后再选，本文不定义任务流程）
```

- **不可逆**：非零号改造体在剧情的关键节点需要选择接受改造、作为朋友、背叛三条分支一旦确认不可回退。
- **FRIEND → CONVERTED**：v0.3 **不允许**。要体验改造体能力需新开档或后续企划提供特殊途径。
- **BETRAYED**：不再获得改造体声望正增长；击杀改造体仍可得信用点/治安部声望/降警觉。

## 3. 身体电量系统

### 3.1 资源定义

| 字段 | 类型 | 默认 | 说明 |
| --- | --- | --- | --- |
| `power.current` | float | 100 | 当前电量 kJ |
| `power.max` | float | 100 | 上限；可被科技树/研究提升 |
| `power.dailyDrain` | float | 5 | 每日自然消耗 |
| `power.billRestore` | float | 5 | 支付电费恢复量 |
| `power.nightOutCost` | float | 5 | 夜间外出消耗 |

仅 `ZERO` / `CONVERTED` 拥有电量池；`FRIEND` / `BASE` 该面板隐藏。

### 3.2 每夜结算顺序（固定）

1. **支付电费（可选）**：扣信用点 → `power += 5`（能量增加均受上限限制）。
2. **未外出奖励**：若已支付电费且当晚未外出 → `power += 5`。
3. **自然消耗**：`power -= 5`（每日固定）。
4. **夜间外出**：若玩家选择"亲自外出"→ `power -= 5`；夜间外出发生在**闭店后**，不影响当日营业、不会错过客人。
5. **充电交互**：若当晚与电池/充能器/电流转换器交互，按 §3.3 结算。
6. **钳制**：`power = clamp(power, 0, max)`。
7. **归零检查**：若 `power <= 0` → 标记强制休眠（§3.5），**次日**生效。

> 净变化：付电费 + 留店 = **+5**；付电费 + 外出 = **−5**；不付 + 留店 = **−5**；不付 + 外出 = **−10**。实现时拆成 `billRestore`、`nightStayBonus`、`dailyDrain`、`nightOutCost` 四个 modifier，便于调参。

### 3.3 充电源与换算

| 来源 | 交互 | 换算（建议初值） | 成本 | 限制 |
| --- | --- | --- | --- | --- |
| 电池（原版物品） | 工作台/快捷交互新增"为身体充电" | 1 电池能量单位 → 1.0 kJ | 消耗电池 | 需持有电池 |
| 充能器（原版设施） | 夜间交互新增"身体充电" | **+3 kJ/晚**（原版充能器基准；科技树可提升） | 占用当晚充能位 | 不能与设备充电同时 |
| 电流转换器 | 接入电网 | 每 1 kJ 收费 1.5 信用点 | 信用点 | 受电网容量/断电事件影响 |
| 对外供电接口（反向） | 把身体电量供给设备 | 1 kJ → 设备 1 能量单位 | 身体电量 | 用于换人情/情报，不直接回充 |

> 所有换算写入 `config/power.json`，便于平衡；数值为建议初值。

### 3.4 夜间外出

- **时机**：夜间外出发生在**闭店后**（关店 ≠ 过夜；点睡袋/睡觉才进入营业结束结算），因此**不影响当日营业、不会错过当晚客人**。
- **原版限制**：每晚 **1 次**机会，垃圾场/配给站/杰克逊博士店**三地点共用**；去过一处当晚不能再出门；**次日普通顾客名额 −1**（"短眠者"特性不计）；重伤、"全站严打"、广场恐惧症休息期不可外出。
- 外出目的：采购、见人、执行需要玩家亲自到场的行动（后续企划）、躲避某些事件。
- 外出代价：−5 kJ；若电量不足以支付，仍可外出但外出结束后进入归零检查。
- 未外出：正常接待客人；若支付电费则额外 +5 kJ。
- **设计口径**：v0.2 的"夜间外出不会错过客人"理解为"改造体无需睡眠，但是需要充电"；与原版短眠者相同。

### 3.5 电量归零：强制休眠

触发后，**次日**获得状态 `DORMANT`：

- 无法使用改造体植入工具制造/改造；
- 无法指派夜间指令；
- 无法执行手术改造/植入物过夜转化；
- 可以正常开店、卖普通商品、接待顾客（但是会提前闭店导致顾客数量减少90%向下取整，普通顾客不会少于1人，重要npc和额外顾客不受影响）；
- 警觉度额外 +10（判定"店铺经营时间异常"）；
- 电量为0时每日自动恢复 1 kJ（提示提前闭店并使用了备用太阳能板充电）；若电量恢复到 >0，可配置为当日解除封锁（默认 true）；
- 连续两天为 0 时，强制恢复到 10 kJ 并弹出提示，启动后备隐藏能源，获得1个空的能量电池（仅一次，防死锁）。

### 3.6 电量与科技树

科技树节点可提升：`power.max`（+20/级）、`power.dailyDrain`（−1/级，最多5次）、`power.billRestore`（+2/级）、对外供电接口数量（+1/级，上限 6）。

## 4. 改造体声望与网络

### 4.1 声望模型

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `aug.rep` | int | -100..100 |
| `aug.repCap` | int | 由身份决定：ZERO/CONVERTED=100，FRIEND/BASE=99，BETRAYED=-100 锁定 |
| `aug.repLocked` | bool | 背叛后锁定，不再接受正增长 |

> **实现说明（重要）**：原版 `StoreReputation` 的读写方法按固定派系写死（治安部/革命军/黑市/下层/上层/卡特尔），**没有官方插槽新增"改造体"派系**。因此改造体声望采用 `ModData` 独立变量 + 自建面板（PaperUI/ModConfigWindow），不改原版派系栏；这样避免牵动存档、结局与派系 UI。UI 上仍呈现为"改造体声望"。

**获取途径（BASE/FRIEND/QUEST）**

- 卖给改造体顾客物品且未击杀：（按交易额与原版其他阵营统计方式相同）；
- 制造改造体（仅friend身份）：+10；
- 完成改造体顾客的请求（随机任务）：+5；
- "指出伪装破绽"：+1-3（每个改造体可能有多项破绽，每指出一个都+1）；
- 改造体灭绝事件之外的友好行为：按事件配置。

**流失途径**

- 背叛：锁定 -100；
- 主动击杀改造体：不降低声望（v0.2 规则），但滥杀（警觉度<30）会降低声望且会降低该改造体网络对你的信任（叙事层，后续）；
- 任务失败/未完成承诺等行为：−5~10。

**硬规则**

- 一般击杀改造体**不减少**改造体声望，但滥杀（警觉度<30）会降低声望；
- `FRIEND` 声望到 99 后不再增长，UI 显示"朋友之上，需要成为同类"；
- `ZERO` 初始 100，声望不下降（除非后续剧情）。

### 4.2 声望阈值

| 阈值 | 效果 | 适用身份 | 实现要点 |
| --- | --- | --- | --- |
| ≥20 | 每天额外 1 名改造体顾客；条件：至少 1 个 `HIDDEN` 改造体；`TASKED` 不计入 | 全部 | 复用 `StoreClientManager.AddClient/TryAddClient`，避免挤掉剧情来客、正常顾客、长期储存避免sl后不来额外顾客 |
| ≥30 | 解锁"改造体之友"任务入口（状态门控） 不显示在“意见箱”中| BASE | 只改 `QUEST` 状态，任务内容后续 |
| ≥40 | 日历显示改造体的行动计划 | ZERO/CONVERTED/FRIEND/BASE | 只读展示，不可改 ZERO会看到自己指派的任务|
| ≥60 | 改造体顾客携带信用点/物品质量提升（建议 +25%） | 全部 | 生成顾客时乘系数 |
| ≥80 | 改造体夜间偶尔留下礼物（概率基于声望%/2，从物品池中抽取一个，声望越高价值越高） | 全部 | 闭店结算 roll |
| ≥100 | 掌控全部改造体；可下达夜间指令 | ZERO/CONVERTED | ZERO 初始满足；CONVERTED 到 100 解锁 |
//注释，在CONVERTED未达到声望100前仍可命令自己改造出来的改造体，但是会有未掌控改造体随机进行活动。
> `ZERO` 初始 100，因此 ≥20/40/60/80 效果天然生效；`ZERO` 无"未被掌控改造体"，≥40 的日历展示对其无意义（可显示"全部可控"）。

### 4.3 改造体 NPC 状态

| 状态 | 枚举 | 行为 | 是否计入额外顾客 | 是否可指派 |
| --- | --- | --- | --- | --- |
| 隐藏 | `HIDDEN` | 正常生活，偶尔到店（购买/捐赠/请求/破绽） | ✅ | ✅（指派后转 TASKED） |
| 执行任务 | `TASKED` | 当晚不在店铺出现 | ❌ | 当晚已占用 |
| 失控 | `AUTONOMOUS` | 自主行动；>=40 日历可见；行动加警觉度 | ❌（执行自主行动） | ❌（CONVERTED <100 / FRIEND） |
| 暴露 | `EXPOSED` | 被治安部标记，可能被调查/抓捕，可能会在一段时间后死亡或者重新进入隐藏状态 | ❌ | ❌ |
| 死亡 | `DEAD` | 移除网络 | ❌ | ❌ |

**控制权**

- `ZERO`：所有己方改造体 `owner=player`，无 `AUTONOMOUS`。
- `CONVERTED`：成为`CONVERTED`时按照游戏内时间产生`AUTONOMOUS`，声望 <100 时 按照`AUTONOMOUS`随机进行的行动增加/减少`AUTONOMOUS`，大部分`AUTONOMOUS`执行隐藏指令的概率最大，提前1-3天会集结规划进行行动，同一天不会有多于两项`AUTONOMOUS`的行动生效；到 100 全部收回。
- `FRIEND`/`BASE`：所有改造体 `AUTONOMOUS`，玩家只能观察/交互，不能指派。

### 4.4 改造体网络容量

- 建议软上限：改造体数量太多警觉度和暴露的改造体数量会增加，使玩家可用的改造体很难超过1000。
- 硬上限由性能/存档决定（建议 9999），达到后无法再转化。
- 后期解锁的任务类型会需要使用更多的改造体、死亡概率更高。
- 指派任务界面中减少操作，避免单独指派某一个普通npc执行任务，仅剧情中的重要npc有独特任务可以单独选择任务。其他npc仅使用下层区、上层区、治安部、黑市、革命军等派系划分，为zhon，重要npc使用原版派系。

## 5. 植入物系统

### 5.1 物品层级与规格

| 层级 | 物品 ID | 制造解锁 | 可销售方式 | 基础感染率 | 备注 |
| --- | --- | --- | --- | --- | --- |
| 基础 | `implant.basic` | 初始 | 仅容器遮掩 | 35% | 最早可用 |
| 可食用/水溶性 | `implant.soluble` | 科技树 T2 | 食物/饮水/酒精 | 50% | 需对应容器商品 |
| 伪装型 | `implant.disguised` | 科技树 T2/T3 | 伪装成药物/日用品 | 55% | 可正常标价 |
| 光学迷彩 | `implant.camo` | 科技树 T3 | 0 信用点摆放，顾客不可见 | 70% | 顾客"顺手拿走" |
| 剧情特制 | `implant.story.*` | 后续企划 | 剧情专用 | — | 本文只留接口 |

**通用字段**

- `tags`: `contraband.high`, `implant`, `concealable`（按层级）
- `weight/占格`: 基础 1×1；可食用 1×1；伪装 1×1；光学迷彩 1×1（建议都 1×1，工作台 2×2）
- `value`: 制造成本 + 售价基准（建议基础 40 cr，可食用 70，伪装 120，迷彩 180）
- `stack`: 建议 5（便于批量）

### 5.2 制造

- **设施**：改造体植入工具，占格 2×2，标签 `workbench.aug`，仅在店铺可放置。
- **配方**（建议初值）：

| 产物 | 电子零件 | 其他材料 | 时间 | 备注 |
| --- | --- | --- | --- | --- |
| 基础植入物 ×1 | 2 | 废金属 ×1 | 即时/工作台 | 初始配方 |
| 可食用/水溶性 ×1 | 3 | 化学试剂 ×1 | 即时 | T2 |
| 伪装型 ×1 | 3 | 塑料 ×2 | 即时 | T2/T3 |
| 光学迷彩 ×1 | 5 | 光学元件 ×1 | 即时 | T3 |
| 高级植入物（剧情） | — | — | — | 后续 |

- 电子零件来源：废料客购买、3D 打印机、改造体"拾荒/研究"指令。
- 制造消耗行动：建议每次制造消耗 1 个"工作台使用次数"或固定时间，不做成实时等待（保持节奏）。

### 5.3 销售与检测模型

**销售渠道**

| 渠道 | 可见性 | 检测方式 | 暴露后果 |
| --- | --- | --- | --- |
| 容器遮掩（净水药片、水质试纸等） | 顾客看不见内容物 | 结账时按 `concealment` 判定 | 发现→必报警 |
| 食物/饮水/酒精（可食用） | 混入商品 | 顾客食用前/后判定 | 发现→必报警 |
| 伪装成合法物品 | 外观合法 | 顾客使用/鉴别判定 | 发现→必报警 |
| 光学迷彩 0 信用点 | 顾客不可见 | 仅"是否顺手拿走"判定 | 发现→必报警（极低概率） |
| 直接交易（高风险） | 明示 | 必定暴露 | 必报警，不建议 |

**检测概率（建议公式）**

```
P_detect = base_detect(tier)
         + alertness * 0.004
         + detectorRate(target) * 0.3
         - concealment(item) * 0.25
```

- `base_detect`：基础 0.45 / 可食用 0.35 / 伪装 0.30 / 迷彩 0.10。
- `detectorRate(target)`：目标"鉴别植入装置"能力（0–1），由警觉度与身份决定（见 §9）。
- `concealment(item)`：容器遮蔽系数（0–1），净水药片 0.6，水质试纸 0.5，普通盒子 0.3。
- 检测成功 → **必定报警**（v0.2 硬规则）：治安部警觉度 +、犯罪值 +、该顾客关系恶化；玩家可能被调查。
- **实现挂接**：优先复用 `StoreClient.CanClientExposeAnyFeature` / `InspectItemDeep` / `ContrabandHelper.StartInspection` / `SecData`，不要自建顾客 AI。
- **一次性预警**（可选难度项）：首次检测成功时改为"顾客犹豫并警告"，第二次才报警；默认关闭，硬核开启。

**光学迷彩特殊逻辑**

- 物品以 0 信用点上架，顾客结算时看不到该物品；
- 顾客离店时按 `camo_take_rate`（建议 60%）判定"顺手拿走"；
- 拿走即视为售出，进入感染队列；未拿走则物品留在柜台（次日可再判定）；
- 顾客不知道拿了什么，**不会主动报警**；但若治安部搜查柜台发现，按普通违禁品处理。
- **展示柜风险（重要）**：原版展示柜中的违禁品/赃物每天按热度掷骰，任意一件成功即当天生成盘查员；因此光学迷彩**不能放展示柜**，必须用柜台/隐藏区/暗格，绕开 `SecurityCheckDisplayCase`。

### 5.4 销售记录

每笔植入物销售写入 `PendingInfection`：

```json
{
  "customerId": "npc_123",
  "implantTier": "basic",
  "soldDay": 12,
  "soldVia": "container",
  "detected": false,
  "relatedNpcIds": ["npc_124", "npc_125"]
}
```

- `detected=true` 的销售不进入感染队列（顾客已警觉/报警）。
- 每个顾客可同时挂多个待感染记录，但同一晚只结算一次。

## 6. 感染与报到

### 6.1 每夜感染判定

闭店结算阶段，对每条 `PendingInfection` 执行：

```
P_infect = base_infect(tier)
         * (1 - protection(target))
         * (1 - alertness * 0.004)
         * (1 + rep_bonus)
         - vaccine_penalty(target)
P_infect = clamp(P_infect, 0.02, 0.95)
```

- `base_infect`：基础 0.35 / 可食用 0.50 / 伪装 0.55 / 迷彩 0.70。
- `protection(target)`：目标防护等级（0–0.9），上层/高警觉度更高。
- `rep_bonus`：声望 ≥60 时 +0.1；≥80 时 +0.15（体现"改造体配合"）。
- `vaccine_penalty`：纳米机器疫苗（上层高警觉度时）−0.2~0.4。
- 成功 → 目标转为 `HIDDEN` 改造体，次日"报到"；失败 → 记录失效，顾客无异常（可再次购买/再尝试）。
- **实现时机**：使用 `ModHook.OnGoingSleepLate` / `OnHandlingNightlyServicesLate`；不要直接改 `StoreDate.AdvanceDay`（会绕过事件/房租回填）。结算结果追加到 `NightLog` 夜间报告（需 patch 报表构建）。

### 6.2 关联 NPC 扩散

- 每条记录在成功感染主目标后，按 `relatedNpcIds` 各做一次**低概率**扩散判定（建议 20%），成功则一并转化。
- 关联 NPC 不消耗植入物，体现"接触传播"；但每夜全局扩散上限建议 2 人，防止爆炸。
- 剧情重要 NPC 默认免疫普通扩散（后续企划用剧情特制植入物）。

### 6.3 报到流程（次日开店）

1. 新改造体在次日开店时出现在店门口/店内，触发"报到"交互；
2. 玩家选择：接纳（入网） / 拒绝（放走，转为 `AUTONOMOUS`）。
3. 接纳后：
   - 状态 `HIDDEN`；
   - 记录身份等级、防护、携带信用点；
   - 发放**改造经费**（§10）；
   - 加入网络列表，可被指派夜间指令。
4. 拒绝后：该 NPC 转为 `AUTONOMOUS`，仍可能自主行动并加警觉度；玩家可后续击杀。

### 6.4 隐藏期行为

- `HIDDEN` 改造体像正常人生活；
- 每日有概率到店（建议 10% + rep/1000），到店类型见 §7；
- 玩家可随时在其到店时"指出破绽"（§7.2）；
- 若警觉度高，`HIDDEN` 可能被治安部抽查 → `EXPOSED`。

## 7. 改造体顾客行为

### 7.1 到店类型

| 类型 | 权重（建议） | 行为 | 玩家收益 |
| --- | --- | --- | --- |
| 购买 | 40% | 买普通商品/植入物相关材料 | 正常交易利润 |
| 捐赠 | 20% | 赠送信用点/材料/物品 | 白嫖资源 |
| 请求物品 | 30% | 请求某物品（用于改造身边人） | 完成后 +声望 +经费 |
| 破绽机会 | 10% | 伪装出现明显破绽，可指出 | 声望+信用点+物品 |

### 7.2 "指出破绽"交互

- 仅对 `HIDDEN` 改造体顾客可用；
- 玩家选择指出部位（眼睛/接口/行为/证件等，后续可做小游戏）；
- 判定：`P_success = 0.6 + rep*0.002 - alertness*0.002`；
- 成功：声望 +1~3、信用点 +20~60、随机物品；该 NPC 进入"学习"冷却（3 天）；
- 失败：声望 −1，顾客不悦离开（不报警）；
- 每 NPC 每日最多 1 次。

### 7.3 ≥20 额外顾客

- 每晨结算：若 `aug.rep >= 20` 且 `count(HIDDEN) >= 1`，则当日额外生成 1 名改造体顾客；
- 排除 `TASKED`/`AUTONOMOUS`/`EXPOSED`/`DEAD`；
- 额外顾客不占用原版顾客名额（建议作为独立 slot），避免挤掉正常客流；
- 若当日已有随机改造体顾客，仍叠加（最多 +1）。

### 7.4 ≥60 质量提升

- 改造体顾客携带信用点 ×1.25、物品品质 +1 档；
- 与额外顾客叠加。

### 7.5 ≥80 夜间礼物

- 闭店结算 25% 概率触发，每夜最多 1 份；
- 礼物池：电子零件、医疗品、信用点、稀有材料；
- 礼物来源为随机 `HIDDEN` 改造体（叙事提示"门口多了一个包裹"）。

## 8. 夜间指令

### 8.1 指令面板

- 触发时机：闭店结算完成后、进入"夜晚"阶段；
- 可用对象：`owner=player` 且 `status=HIDDEN/IDLE` 的改造体；
- 每个改造体每晚只能分配 1 条指令；
- 未分配的改造体保持 `HIDDEN`（可能触发到店/礼物）；
- `DORMANT` 玩家无法打开指令面板（§3.5）。

### 8.2 指令表

| 指令 | 产出（建议） | 警觉度 | 风险/失败 |
| --- | --- | --- | --- |
| 拾荒 | 废金属 2–4、电子零件 1–2 | +1 | 5% 受伤（当晚无效） |
| 赚取信用点 | 40–90 cr | +1 | 10% 只拿到一半 |
| 联络人脉 | 指定派系声望 +3~6 | +2 | 5% 敌对派系 −2 |
| 进行研究 | 科研点 +1~2 | +1 | 无 |
| 抓捕人类 | 获得"人类"×1 | +6 | 15% 失败/受伤；高警觉度更高 |
| 提供货物 | 指定货物 1–3 件（交易/偷窃） | +3 | 20% 只拿到一部分；可能触发调查 |
| 制造世界事件 | 见 §8.3 | +8~15 | 高概率调查/声望变化 |

> 警觉度增量为**基础值**，实际 = 基础 × (1 + 失控改造体比例) × 难度系数。

### 8.3 世界事件选项（核心功能版）

| 事件 | 效果 | 警觉度 | 冷却 | 备注 |
| --- | --- | --- | --- | --- |
| 袭击供水站 | 未来 3 天净水价格上涨/短缺 | +12 | 5 天 | 影响原版经济 |
| 焚烧农场 | 未来 3 天食物价格上涨/短缺 | +12 | 5 天 | 影响原版经济 |
| 制造停电 | 当晚/次日部分设施不可用 | +10 | 4 天 | 可能误伤自己 |
| 压低警觉度 | 警觉度 −8~12 | +5（先加后减，净降） | 3 天 | 不能连续使用 |
| 散布谣言 | 治安部调查进度 −5 | +6 | 3 天 | 对 ZERO 的逃逸进度有效 |
| 袭击巡逻 | 治安部声望 −、警觉度 + | +15 | 7 天 | 高风险高回报 |

> 世界事件的**具体叙事文本与后续影响**属后续企划；v0.3 只定义数值接口与经济影响挂点。

### 8.4 结算顺序

1. 玩家分配指令；
2. 逐条结算产出（先算资源，后算风险）；
3. 汇总警觉度增量，更新 `alertness`；
4. 被指派改造体转 `TASKED` → 次日晨恢复 `HIDDEN`；
5. 触发调查检查（§9.4）。

## 9. 治安部追查与警觉度

### 9.1 两层进度

| 进度 | 适用 | 初始 | 增长 | 满值效果 |
| --- | --- | --- | --- | --- |
| 逃逸进度 `escapeProgress` | ZERO | 0 | 每日 +1~2；改造体行动额外 + | 100 时激活警觉度系统 |
| 警觉度 `alertness` | 全部（激活后） | ZERO 0；CONVERTED/FRIEND 20 | 行动/事件/报警 | 0–100，影响全局难度 |

### 9.2 警觉度效果模型

```
protectionRate   = clamp(0.10 + alertness*0.006, 0, 0.90)   // 顾客有防护的概率
detectorRate     = clamp(0.05 + alertness*0.005, 0, 0.80)   // 能鉴别植入装置的概率
alarmOnDetect    = 1.0                                       // 发现必报警（硬规则）
conversionDifficulty = 1 + alertness/100 * 0.8               // 感染/手术难度系数
vaccineChance    = clamp((alertness-50)/100, 0, 0.5)         // 上层目标纳米疫苗概率
```

- `protectionRate` 作用于顾客生成：有防护的目标感染率、手术进度受罚；
- `detectorRate` 作用于检测判定（§5.3）与搜查；
- `vaccineChance` 仅对"上层/高身份"目标生效，命中则 `vaccine_penalty`。

### 9.3 报警与犯罪

- 检测到植入物/改造体 → **必定报警**；
- 每次报警：`crime += 5~10`，`alertness += 3~5`，治安部声望 −；
- 犯罪值累积到阈值触发调查事件（建议 30/60/100）：巡逻加强、随机搜查、上门调查；
- 调查事件可通过世界事件"散布谣言"降低进度，或击杀改造体转移视线（降警觉）。

### 9.4 调查检查（每日）

```
if alertness >= 60 and crime >= 30: 触发随机搜查事件（概率 = (alertness-50)/100）
if alertness >= 85: 触发上门调查（高概率）
if escapeProgress >= 100 and ZERO: 警觉度激活，进入"被追查"状态
```

> 调查事件的具体对话/执法流程属后续企划；v0.3 定义触发条件、概率与后果接口。

### 9.5 反制手段

| 手段 | 效果 | 代价 |
| --- | --- | --- |
| 击杀改造体 | 警觉度 −3（递减，见 §10） | 消耗时间/风险 |
| 世界事件"散布谣言" | 逃逸进度 −5 | 警觉度 +6 |
| 世界事件"压低警觉度" | 警觉度 −8~12 | 冷却 3 天，先 +5 |
| 低调经营 | 当日无改造体行动则警觉度 −1 | 损失产能 |

## 10. 击杀改造体与改造经费

### 10.1 击杀改造体（全身份通用）

- 触发：在原版遭遇/店铺内对改造体使用武器；
- **原版奖励（沿用）**：
  - 信用点 = `100 + (当前天数 − 改造体引入日)`，钳制 **100~250**；"改造体危机"开局 ×1.25（但零号与该特质互斥，通常不触发）；
  - 治安部声望 **+8**；革命军/黑市/下层区各 **+2**；
  - 累计 10 杀解锁成就 `ACH_AUG_HUNTER`。
- **Mod 追加**：
  - **警觉度 −3**（每日前 3 次有效，之后递减到 −1，防止刷）；
  - 改造体声望不变（v0.2 硬规则）。
- 风险：
  - **误杀代价极高**：原版记"过失杀人"250（<25 天）/500（25–49 天）/750（≥50 天）犯罪值，并扣多派系声望，豁免权不能抵消；
  - 误杀 `HIDDEN` 己方改造体会减少网络（`CONVERTED`/`ZERO` 需确认）；
  - 公共场合击杀可能触发治安部调查。

### 10.2 改造经费（ZERO / CONVERTED）

成功改造一名 NPC 时（报到接纳或自主转化成功），按目标身份等级发放：

> 原版没有独立的"中层区"派系，身份等级按**顾客派系 + 模板**映射：下层 = 下层区/拾荒者/水贩；中层 = 工程师/医生/商人等；上层 = 上层区。经费基准取 `StoreClient.clientCash` / `GetBudget()` 的档位。

| 身份等级 | 经费（信用点） | 说明 |
| --- | --- | --- |
| 下层 | 60 | 顾客到店携带信用点基准 |
| 中层 | 150 | |

## 15. Mod 兼容与边界

- **原版"改造体危机"**：ZERO 强制互斥并抑制随机事件；BASE/FRIEND 保留原版。互斥用官方 `StartingPerk.incompatiblePerks`，不要硬改特质表。
- **改造体声望**：原版 `StoreReputation` 无新派系插槽，采用 `ModData` 独立变量 + 自建面板，不改原版六派系栏，避免牵动存档/结局。
- **派系声望类 Mod**：独立存储、并排显示，避免覆盖原版派系 UI。
- **特性商店类 Mod**：若也注册特质，需在加载顺序上兼容；冲突时以"零号改造体"优先并提示。
- **物品类 Mod**：自定义植入物 ID 加前缀 `aug.`，避免撞 ID；使用 `ModItemDirectory` 注册。
- **原版改造体终局**：原版引入 50 天后存在度归 0 + 许可证满 25 天会触发"清除完毕"；ZERO 需接管/延缓该判定，否则后期无改造体可经营。
- **夜间外出**：每晚 1 次、三地点共用、次日普通顾客 −1、重伤/严打禁行；夜间指令/手术不得突破这些限制。
- **展示柜**：违禁品/赃物放展示柜每天掷骰触发盘查；光学迷彩不得放展示柜。
- **版本基线**：本机 BuildID 26496118；BWIKI 称 1.0、生态文档称 0.46D/100-Rev1、MCP Bridge 称 100-REV6——需用户在游戏内确认后锁定 `manifest.xml` 的 `GameVersions`。
- **多人/联机 Mod**：v0.3 不承诺兼容；改造体网络为本地状态。
- **本地化**：所有文本走 key（`ModHelper.GetLocalized`），预留中/英。

## 18. 验收标准（核心）

1. 选择"零号改造体"后无法同时选择"改造体危机"，存档不产生原版随机改造体。

7. "人类"物品可通过植入物过夜或手术转化；手术工具特例生效；自主改造体不交付"人类"。
8. 科技树三轨判定正确：ZERO 不能花钱，CONVERTED 低阶可买/高阶需开放/科研免钱。
9. 击杀改造体给信用点+治安部声望+降警觉，且不降改造体声望。
10. 改造经费按身份等级入账。
