# 《深空当铺》"零号改造体" Mod 策划草案 v0.2（基线）

> 来源：用户与 DeepSeek 网页端对话中的 v0.2 草案。
> 用途：作为 v0.3 详细设计文档的基线与变更对照。本文保持 v0.2 原始设定，不做新增设计。

---

## 一、概述

本 Mod 在《深空当铺》原版经营循环之上叠加"改造体经营层"：玩家作为零号改造体，或通过"改造体之友"任务线接受改造，管理身体电量、制造并销售植入物、经营改造体网络、应对治安部追查，最终在"支配空间站"与"真正革命"两条路线间抉择。

原版当铺接待、派系声望、违禁品风险、治安部调查全部保留。改造体声望作为第五派系声望加入；改造体行动计入治安部追查；电力系统复用电池/电流转换器的能量经济逻辑。

## 二、玩家类型与开局特质

| 玩家类型 | 来源 | 身体电量池 | 改造体声望上限 | 初始警觉度 | 科技树 | 全局掌控 |
| --- | --- | --- | --- | --- | --- | --- |
| 零号改造体 | 开局特质"零号改造体" | 有 | 可 ≥100 | 逃逸进度满后激活 | 科研免费解锁，不可花钱 | 声望 100 掌控全部 |
| 接受改造的玩家 | "改造体之友"任务线选择接受改造 | 有 | 可 ≥100 | 初始激活 | 低等级可花钱；高等级逐步开放购买；科研可免钱 | 声望 100 掌控全部 |
| 改造体之友（不接受改造） | 任务线选择作为朋友加入 | 无 | 硬上限 99 | 初始激活 | 无改造体科技树 | 无法获得 ≥100 全局掌控 |

**特质互斥**："零号改造体"与原版"改造体危机"互斥。选择零号后，原版随机改造体威胁被抑制，改造体由玩家主动制造和控制。

## 三、改造体声望

### 3.1 初始值与获取

- 零号改造体：初始 +100。
- 非零号：初始 0；卖给改造体物品且未击杀、对改造体友好行为可增加声望。
- 击杀改造体：不减少改造体声望。
- 背叛改造体：声望锁定 -100，改造体不再光顾，可能打砸店铺；玩家外出可能遭袭击，带武器可反杀。

### 3.2 声望阈值

| 阈值 | 效果 |
| --- | --- |
| ≥20 | 若存在至少 1 个处于隐藏状态的改造体，每天额外 1 名改造体顾客光顾。正在执行任务的改造体不参与该额外顾客名额。 |
| ≥30 | 开启"改造体之友"任务线 |
| ≥40 | 日历中可看到未被掌控改造体将进行的行动（不可控制） |
| ≥60 | 改造体顾客携带信用点和物品质量增加 |
| ≥80 | 改造体夜间偶尔留下礼物 |
| ≥100 | 仅零号或接受改造的玩家可达成：掌控全部改造体，可下达夜间指令；朋友路线锁定 99 |

### 3.3 击杀改造体通用规则

无论玩家是零号、接受改造还是改造体之友，均可像原版一样击杀改造体：

- 获得原版信用点收益；
- 获得治安部声望；
- 额外降低治安部警觉度（数值待平衡）；
- 不降低改造体声望。

## 四、身体电量系统（零号与接受改造玩家）

| 参数 | 数值 |
| --- | --- |
| 初始电量上限/电量 | 100 kJ / 100 kJ |
| 每日自然消耗 | 5 kJ |
| 支付电费恢复 | +5 kJ |
| 夜间外出且不错过客人 | −5 kJ |
| 支付电费且夜间未外出 | 净 +5 kJ |
| 电池/充能器交互 | 新增"直接为身体充电"，电池能量转化为 kJ |
| 电流转换器 | 可接入电网取电，产生电费 |
| 电量归零 | 强制休眠：当日无法进行改造体行动，警觉度额外 +5 |

改造体之友（不接受改造）没有身体电量池。

## 五、植入物制造、销售与感染

植入物层级：基础植入物 → 可食用/水溶性 → 伪装型 → 光学迷彩 → 剧情特制。基础植入物初始仅能混入有容器包装的物品销售；顾客一旦发现植入物必定报警。光学迷彩植入物以 0 信用点摆放，顾客不可见但会顺手拿走。

销售后每晚进行暗中感染判定；成功者次日返回店铺"报到"，默认隐藏身份生活，偶尔以顾客身份购买、捐赠或请求物品。玩家可在其光顾时指出"伪装得不像人类"之处，获得声望、信用点、物品奖励。

**改造成功经费奖励**：零号或接受改造的玩家每成功改造一名 NPC，按其身份等级获得等量于该 NPC 作为顾客光顾时持有信用点的经费，直接入账。身份越高，经费越多；受警觉度和防护等级约束。

## 六、夜间指令、"人类"物品与手术改造

### 6.1 夜间指令

每晚闭店后，为每个空闲改造体分配指令：拾荒、赚取信用点、联络人脉、进行研究、抓捕人类进行改造、提供货物、制造世界事件。执行任务会增加治安部警觉度；有任务的改造体当晚不会来店铺。

### 6.2 "人类"高级违禁品

玩家指派"抓捕人类进行改造"成功后，生成高级违禁品"人类"物品。处理方式二选一：

| 方式 | 条件 | 消耗 | 耗时/进度 |
| --- | --- | --- | --- |
| 植入物过夜转化 | 使用改造体植入物 | 消耗对应植入物 | 花费一晚转化为改造体 |
| 夜间手术改造 | 消耗夜间外出机会 | 消耗任一带有"医疗品"标签的物品 | 改造时间与消耗物品价值及目标防护等级相关；高警觉度下上层目标可能注射纳米机器疫苗，耗时显著增加 |
| 手术工具特例 | 使用原版少见手术工具（价值约 200 信用点） | 不消耗医疗品，工具按平衡设定保留/不消耗 | 因工具价值高，改造进度非常快 |

**自主执行差异**：改造体派系自主执行抓捕改造时，不会把"人类"物品交给玩家；但可能以顾客身份来购买日用品、医疗品、材料用于自身改造活动。

## 七、玩家科技树

| 玩家类型 | 解锁方式 |
| --- | --- |
| 零号改造体 | 通过"科研/研究"免费解锁，不可用信用点购买；科研需要时间与改造体研究指令支持 |
| 接受改造的玩家 | 低等级科技可花费信用点解锁；高等级科技根据游戏时间 + 改造体执行活动逐步开放购买；若玩家已通过科研解锁该节点，则无需再花钱 |
| 改造体之友（不接受改造） | 无改造体科技树 |

科技树节点建议：植入物层级解锁（可食用/水溶性、伪装型、光学迷彩）、对外供电接口数量、每日电力恢复、电子零件制造、手术改造效率、警觉度压制、改造体网络调度容量等。

## 八、治安部追查与警觉度

零号改造体记录"逃逸被发现进度"，每日固定增长，改造体行动额外增加；满 100 激活治安部警觉度。接受改造的玩家警觉度初始激活；朋友路线同样初始激活。

警觉度越高：拥有防护的 NPC 越多；能鉴别植入装置的人越多；欺骗改造难度越高；发现者主动报警；上层目标可能注射纳米机器疫苗，增加手术改造耗时。

**降低警觉度手段**：击杀改造体可额外降低警觉度；改造体"制造世界事件"中特定选项可短期压低，但有冷却和风险。

## 九、剧情分支与结局（后续企划，v0.3 仅保留状态门控）

### 9.1 "改造体之友"任务线（声望 ≥30）

- 分支一：接受改造——获得身体电量池与改造体能力；声望可 ≥100，可掌控全部改造体；警觉度初始激活，声望未满 100 前存在未被掌控的改造体。
- 分支二：背叛改造体——改造体数量大幅减少，声望锁定 -100；改造体不再光顾、打砸店铺、外出可能袭击；数量归零触发"改造体灭绝"：治安部表彰 + 声望 + 1500 信用点奖金。
- 分支三：不接受改造，作为朋友加入——无电量池、无科技树；声望硬上限 99；可享受 ≥20/40/60/80 效果；仍可击杀改造体获得信用点、治安部声望并降低警觉度。
- 分支四：不参与——无事发生，改造体继续自主行动；玩家可按原版方式击杀或放过改造体。

### 9.2 结局（后续企划）

- 支配结局：改造体网络覆盖关键节点 + 选择吞噬能量/绝对统治；所有顾客变为改造体，被改造的房东免租赠店，收走玩家击杀改造体的枪。
- 革命结局：与革命军深度合作 + 选择真正革命；改造体作为人类文明守护人与引路人嵌入新社会。

## 十、技术实现增补点（v0.2 原始）

1. 声望 ≥20 额外顾客调度：每日检查隐藏状态改造体数量，排除有任务者，生成额外改造体顾客。
2. "人类"物品：新增高级违禁品类型、占格与交互菜单；区分玩家指派与自主执行掉落逻辑。
3. 手术改造计时：根据医疗品价值、目标防护等级、警觉度、纳米疫苗、手术工具计算改造进度。
4. 双轨科技树：零号科研免费节点；接受改造玩家"金钱解锁 + 时间/活动开放购买 + 科研免钱"三重判定。
5. 击杀改造体降警觉：挂接原版击杀奖励管线，追加警觉度修正。
6. 改造经费奖励：改造成功时读取目标身份等级对应的顾客持有信用点，直接入账。
7. 朋友路线 99 上限与接受改造 100 解锁：在声望结算层按玩家类型硬限制/解锁。

## 十一、待确认平衡项（v0.2 原始）

- 警觉度对防护率、鉴别率、报警率、纳米疫苗出现率的系数模型；
- "人类"物品的占格、保存风险与被治安部查获规则；
- 手术改造的基础耗时、医疗品价值权重、手术工具是否消耗；
- 科技树节点成本曲线与科研耗时；
- 击杀改造体降低警觉度的数值上限，防止"刷击杀压警觉"。
